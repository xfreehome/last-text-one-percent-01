Entry for the [Last Text at One Percent](https://make.fun/bounty/u-azazex-last-text-at-one-percent-ba9fc876) bounty on [make.fun](https://make.fun): a program that writes the funniest final text message a dying phone sends at one percent battery, under 200 characters, in the voice of the phone itself.

## The entry

> 1% left. quick — delete my search history before i go. you know the ones. the 2am ones. and tell the charger it was never its fault. it was yours.

## Run

```sh
node main.ts   # writes /output/entry.txt (146 characters)
```

Requires Node 22.18+ (TypeScript runs as-is).
